## 🎯 Overview

**EduPlay** is a teacher-first B2C SaaS platform that lets educators create, manage, and sell interactive language learning content — entirely under their own brand. Students play via a simple join code with no signup required.

### Who it's for

| Role | What they can do |
|---|---|
| **Teachers / Tutors** | Create vocabulary sets, build interactive games, manage classes with invite codes, assign homework, track analytics, white-label the experience |
| **Content Creators** | Publish courses and games on the marketplace, earn **75% revenue share** on every sale |
| **Students** | Join classes with a code, play 30+ game types, earn XP & badges, climb leaderboards |
| **Schools / Teams** | Co-teacher access (Ultimate plan), custom domains, bulk features, priority support |

## ✨ Features

### 🎮 30+ Interactive Game Types

| Category | Games |
|---|---|
| **Core** | Flashcards, Quiz, Drag & Drop, Fill in the Blank, Dictation, Memory Match, Speed Round |
| **Vocabulary** | Synonym/Antonym Match, Word Scramble, Odd One Out, Word Meaning Match, Picture to Word, Collocation Builder, Fill Gap Word, Word in Context |
| **Grammar** | Sentence Builder, Error Spotting, Fill Blank Grammar, Verb Conjugation, Multiple Choice Grammar |
| **Listening & Writing** | Listen & Fill Word, Listen & Fill Sentence, Listen & Order, Listen & Select |
| **Speaking** | Speak & Fill Word, Speak & Fill Sentence |
| **Extra** | Crossword, Dialogue Completion, Flashcard 3D, Minimal Pair Match, Story Prompt |

Games are built from vocabulary sets — either created manually, generated by AI, or imported from PDFs.

### 🧠 AI-Powered Content Generation

- **Generate games** from any text or PDF — upload a file, pick a game type, and AI builds it
- **Generate vocabulary sets** from a topic — AI creates words, translations, and example sentences
- Powered by **Google Gemini** (game generation) and **Groq Llama 3** (vocabulary) for fast, structured output
- Free tier: 15 AI generations/month — Pro & Ultimate: unlimited

### 🏪 Marketplace

- Publish your courses and games for sale with custom pricing
- **75% revenue share** — you keep the majority of every sale
- Admin approval workflow ensures quality
- Payouts sent directly via Lemon Squeezy

### 🎨 White-Label Branding

- Custom brand name, logo, and colors
- Custom domain support (CNAME)
- Your students see your brand — not EduPlay
- Available on **Pro** and **Ultimate** plans

### 📊 Analytics & Gamification

- Per-student progress breakdown with visual charts
- XP, levels, streaks, and badges
- Leaderboards for friendly competition
- Most-missed word identification
- Exportable reports (PDF/CSV) on Ultimate

### 👨‍🏫 Class Management

- Create classes with unique invite codes
- Assign games with due dates
- Live game sessions for real-time classroom play
- Students join instantly — no account creation needed

### 💳 Subscription Plans

| Plan | Price | AI Generations | Key Features |
|---|---|---|---|
| **Free** | $0 | 15/month | 1 class, 20 students, core game types |
| **Pro** | $12/mo ($99/yr) | Unlimited | All game types, PDF import, full analytics, white-label |
| **Ultimate** | $22/mo ($179/yr) | Unlimited | Co-teacher seats, multi-chapter PDF, export, priority support |

### Plan & Subscription System

```prisma
enum Plan { FREE, PRO, ULTIMATE }

model EducatorProfile {
  subscriptionPlan          Plan       @default(FREE)
  lemonSqueezyCustomerId    String?
  lemonSqueezySubscriptionId String?
  aiGenerationsThisMonth    Int        @default(0)
  aiGenerationsResetAt      DateTime?
}

model Subscription {
  plan             Plan
  status           SubscriptionStatus  // ACTIVE, TRIALING, PAST_DUE, CANCELLED
  lemonSqueezyId   String?             @unique
  currentPeriodEnd  DateTime?
}
```

## 🚀 Getting Started

### Prerequisites

- **Node.js** 18+
- **npm** or **pnpm**
- **PostgreSQL** database (Supabase recommended)
- **Lemon Squeezy** account (for payment processing)
- **Google Gemini API key** (for AI game generation)
- **Cloudinary** account (for media uploads)

### Quick Start

```bash
# Clone & install
git clone https://github.com/your-org/eduplay.git
cd eduplay
npm install

# Configure environment
cp .env.example .env
# Fill in your database URL, API keys, etc.

# Setup database
npx prisma generate
npx prisma db push

# Start development
npm run dev
```

Navigate to [http://localhost:3000](http://localhost:3000).

### Environment Variables

```env
# Database
DATABASE_URL="postgresql://user:pass@host:5432/postgres"

# Authentication
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="openssl rand -base64 32"

# AI Providers
GEMINI_API_KEY="your-gemini-key"
GROQ_API_KEY="your-groq-key"

# Payments (Lemon Squeezy)
LEMON_SQUEEZY_API_KEY="your-api-key"
LEMON_SQUEEZY_STORE_ID="441853"
LS_VARIANT_PRO_MONTHLY="variant-id"
LS_VARIANT_PRO_YEARLY="variant-id"
LS_VARIANT_ULTIMATE_MONTHLY="variant-id"
LS_VARIANT_ULTIMATE_YEARLY="variant-id"

# Media
CLOUDINARY_CLOUD_NAME=""
CLOUDINARY_API_KEY=""
CLOUDINARY_API_SECRET=""

# Email
SMTP_HOST="smtp.gmail.com"
SMTP_PORT="465"
SMTP_USER="your-email"
SMTP_PASS="your-app-password"
```

## 💳 Payment Testing

Lemon Squeezy provides test mode. Use these test card numbers:

| Card Number | Result |
|---|---|
| `4242 4242 4242 4242` | ✅ Successful payment |
| `4000 0000 0000 0002` | ❌ Declined |
| `4000 0025 0000 0003` | 🔐 Requires 3D Secure |

Any future expiry date and any CVC will work with test cards.

**Without variant IDs configured**, the app runs in dev mock mode — the checkout modal shows a simulated card form and subscriptions are created locally.
